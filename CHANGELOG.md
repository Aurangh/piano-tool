# Changelog

## 0.3.0 — 2026-11-19
- Standalone app: installable on iPad, iPhone, Android and Linux, with an offline cache and an update banner.
- Storage moved to IndexedDB, with localStorage kept as a fallback.
- Backup files (.json) can be saved and opened; songs can be imported and exported as .txt files.
- Computer-keyboard playing and shortcuts.
- Settings: version, install help and update check.

## 0.2.0
- Full view, with only the staff and keyboard showing.
- Reading-only mode with the keyboard hidden.
- Song library: 9 songs, chord symbols, and Listen / Wait for me / Step modes.

## 0.1.0
- Touch keyboard, synth sound, grand staff.
- Note-reading trainer (6 levels), key-signature quiz, circle of fifths, progress screen.
